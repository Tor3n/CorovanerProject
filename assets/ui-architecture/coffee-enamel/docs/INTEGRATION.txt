LIBGDX / SCENE2D INTEGRATION

The project's gradle.properties reports LibGDX 1.13.1 and Java source level
11. The included helper is compiled against those settings.

The current runtime queues all 33 atlas regions through CoffeeEnamelAssets
during MenuTheme.queue. Access any sprite with theme.components.region(name).
The main AssetManager owns the atlas and fonts; screens must not dispose them.
The matching lamp-on/lamp-off pair is used in the main menu.

For other integrations, load atlas/corovaner-ui.atlas through AssetManager.
Keep the atlas alive while its actors are visible. Use docs/CorovanerUi.java
as an optional nine-patch helper, adding your project's package declaration.
Supply a generated Manrope BitmapFont rather than baking labels.

Example (after the AssetManager has completed loading):

TextureAtlas atlas = assets.get("ui-architecture/coffee-enamel/atlas/corovaner-ui.atlas",
                               TextureAtlas.class);
TextButton.TextButtonStyle style = CorovanerUi.primaryStyle(atlas, font);
CorovanerUi.HoverLampButton button = new CorovanerUi.HoverLampButton(
    "Continue journey", style, atlas);
table.add(button).width(320).height(64);

The helper scales the authored nine-patch borders by 0.5. It uses separate
up/over/down surfaces, a disabled tint, and a 28 x 28 lamp overlay: unlit at
rest/disabled and lit on hover or keyboard focus. The application still owns navigation, keyboard
activation, sound and click actions. Native Scene2D labels remain editable.

ALTERNATIVE IMPORT
The atlas includes split and pad metadata. Skin.getDrawable(name) can create
a NinePatchDrawable from it, but that drawable will use source-pixel border
sizes unless you explicitly scale the patch. The helper handles this.
If repacking with TexturePacker, use ninepatch/*.9.png for surfaces and the
hardware/icon PNGs from sprites/. Do not include duplicate ordinary PNG
versions of the same surfaces. Do not pack the .9.png marker pixels as art.

PIVOTS AND LAYOUT
Coordinates in manifest.json are normalized, top-left image origin.
gauge-face pivot: (0.5,0.89); gauge-needle pivot: (0.5,0.88).
For a Scene2D actor with bottom-left coordinates, originY is
(1 - pivotY) * actorHeight. Align the two world-space pivots before rotating.
At the recommended half-size, the needle is 20 x 80, face 128 x 72.
Clamp the shown gauge angle to the designed arc (about +/-70 degrees).
The knob's triangle is part of the knob: rotate the whole knob uniformly.
For a toggle, move the handle within the socket; preserve both aspect ratios.

FILES AND COLOR
RGBA8888 straight alpha. One atlas page, linear filtering, clamp-to-edge,
8 px gutters, no rotation or whitespace stripping, no mipmaps. UI typography is
Manrope; text is amber #D5A451 on dark surfaces and espresso #21160B on enamel.
The exported icons retain their original warm light pixels; apply an appropriate
tint when composing them on enamel. Font provenance/license: assets/ui/fonts/manrope/.
Maintain source dimensions when regenerating .9.png markers and the atlas.
