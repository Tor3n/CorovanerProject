LIMITS
The Java helper has not been run in the game or an OpenGL render context.
The HTML preview's browser interactions have not been exercised in this
environment: the browser runtime download failed. Its images are embedded,
and its hover/toggle/gauge behavior is implemented for local browser use.
Large texture stretches can elongate surface grain; the transparent frame
can be combined with a separate content layer when that matters.
The kit is a clean component redraw matching the concept, not an exact pixel
extraction of each screen, and it is not a complete Scene2D theme replacement.
