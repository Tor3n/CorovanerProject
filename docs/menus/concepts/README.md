# UI design concepts

**Development references and proposals.** This folder holds UI concept art and
visual studies. Creator requirements remain in the
[UI design guide](../../design/ui-art-direction.md).

- [Coffee-enamel studies](coffee-enamel/README.md): main-menu and travel
  concepts, generation brief, component sheets, stretch examples and offline preview.
- [Earlier menu image](legacy/MainMenu.png): retained historical artwork, not used
  by the current menu.

The screen studies preserve their original scope and limitations. In particular,
the travel concept is a control-material study, not an approved map or travel layout.
Concept captions and example values are not gameplay requirements.

Runtime UI assets and editable component inputs live in
[`assets/ui/Menus`](../../../assets/ui/Menus/README.md). Integration examples and
validation notes live in [the UI kit documentation](../ui-kit/README.txt).
